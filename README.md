# Social Media Sentiment Analysis & Brand Perception

## Overview
Analyzed public sentiment patterns from social media posts to understand user attitudes toward brands and topics using NLP preprocessing and sentiment visualizations.

## Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NLTK / TextBlob, Matplotlib, Seaborn, WordCloud

## Key Steps
- Cleaned raw tweet text (tokenization, stopword removal) and categorized polarity into Positive, Negative, and Neutral sentiments.
